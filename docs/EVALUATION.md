# ADVV CLIP 전환 평가 계획

기준: [SPEC v0.7](../SPEC.md), 2026-10-08. 아래는 평가 설계이며 새 방식의 실험 결과가 아니다.

## 1. 단계와 독립 평가

1차 목표는 사고 블랙박스 단일 프레임에서 목표 N장의 고유 증강 이미지를 얻는 파이프라인이다. 품질·다양성·목표 달성·실패 포함 비용·중단/재개·정리 정책을 먼저 평가한다. 2차로 실제 자율주행 관련 후속 과제의 성능 개선을 검증한다.

CLIP 통과율만으로 현실성과 의미 보존의 정확성을 입증하지 않는다. 검수자는 가능한 한 CLIP 점수를 보지 않고 원본·채택 후보를 비교한다. 물리적 개연성, 사고 존재, 원본 사고 유형의 변경, 편집의 실제 변화량을 별도로 기록한다. 단일 프레임으로 실제 충돌 동역학까지 판정했다고 주장하지 않는다.

## 2. 파이프라인과 비용 지표

| 지표 | 정의 |
| --- | --- |
| 목표 달성률 | 고유 채택 수 / 목표 N |
| 완료 | N장과 필수 artifact·export/report 저장 완료 |
| export yield | 고유 채택 수 / 전체 candidate attempt 수 |
| 결과 집계 | 최소 장부의 accepted/rejected/duplicate/error/interrupted 수 |
| 원본별 기여 | 원본/사고 group별 시도·채택 수; 쉬운 원본 쏠림 확인 |
| 시도 비용 | 성공/실패를 포함한 attempt 시간 분포와 단계별 시간 |
| 획득 비용 | 각 accepted cost, 전체 active/채택 수, pending 비용 |
| 재현/복구 | recipe 고정, count/시간 중복 없음, 삭제 journal 복구 |

분모 0은 null이다. 기술 재시도는 같은 attempt 내부 비용으로, 새 계획은 새 attempt로 센다. 초기화·segmentation·기존 정리·모델 재로드·마지막 export 비용도 active에 포함한다. pause 시간은 제외하고 crash의 부분 측정 비율을 같이 보고한다. 초기화/종료 비용을 빼고 측정한 단계 처리량은 전체 획득 비용과 구분한다.

기본 정책은 비채택의 상세 CLIP 점수와 실패 항목을 남기지 않는다. 그러므로 저장하지 않은 탈락 점수 분포/항목별 오판 통계를 나중에 계산할 수 있다고 주장하지 않는다. 채택 기록의 점수와 전체 outcome 집계는 이용할 수 있다.

## 3. 채택 이미지 사람 검수

| 항목 | 확인할 내용 |
| --- | --- |
| 시각적 개연성 | 크기·접지·물체 경계/가림이 자연스러운가 |
| 사고 의미 | 일반 교통으로 바뀌지 않았으며 사고 상황으로 보이는가 |
| 원본 사건 변화 | 사고 유형·차량 관계가 바뀌었는가; 5번이 이를 직접 검증하지 않음을 구분 |
| 희소 실제 상황 | 전복·부양·비정상 방향 자체를 비현실적으로 간주하지 않는가 |
| 다양성 | 원본과 거의 같거나 같은 편집만 반복되지 않는가 |

채택 이미지 공동 적합률, 의미 변경 비율, 검수자 불확실률, 표본 수를 보고한다. 같은 사고 영상의 여러 프레임은 독립 표본으로 과대 계산하지 않는다. near-duplicate는 먼저 분석 지표로 사용하며 현재 exact duplicate 제외 외의 사후 채택 조건으로 추가하지 않는다.

**채택된 것만 검수해서는 적합한 후보의 오배제율을 추정할 수 없다.** 기본 삭제 정책에서는 탈락 이미지 재검수와 고정 전체 후보 pool의 필터 ablation이 불가능하다는 한계를 보고한다.

## 4. 고정 문장과 정책 검증

CPU 정책 검사는 유효 점수의 32가지 Boolean 조합, 동점과 숫자 오류, 5번 필수 조건을 검증한다. 모델 품질과는 별개다. 문장은 [clip_criteria_v1.json](../prompts/clip_criteria_v1.json)의 정확한 10개를 사용하며 구현 편의로 번역·재작성하지 않는다.

모델 checkpoint, 전처리, 문장, margin을 선택할 평가 표본은 최종 성능 보고용 표본과 분리한다. 현재 margin=0과 3-of-4 AND mandatory-5 정책은 사용자 합의다. 통과율을 높이려고 run 중 바꾸지 않는다. 향후 변경하면 새 정책 버전과 별도 run을 사용한다.

필터 없음/물리 1–4만/사고 5만/전체 정책을 공정하게 비교하려면 동일 후보 pool이 필요하다. 이 연구용 보관은 현재 기본 삭제 요구와 별개의 작업이며 **보관 허용이 없는 상태에서 옵션으로 몰래 활성화하지 않는다.** 새 연구 범위가 정해지기 전에는 해당 ablation과 탈락 오배제율을 미평가로 남긴다. 이미 삭제한 후보를 완전히 복원했다고 보고하지 않는다.

## 5. 후속 성능 평가

후속 과제와 GT가 준비되면 원본만, 일반 증강, DragFlow 후보, CLIP 선별 ADVV의 효과를 비교한다. 데이터 양·학습 step·seed·라벨 검수 기준을 맞추고 생성/선별 비용을 함께 보고한다.

같은 사고/촬영 영상 group을 기준으로 train/val/test를 증강 전에 고정하고 train만 증강한다. 파생본은 원본과 같은 group이다. 최종 평가는 독립적인 실제 데이터로 구성한다. 사고 의미를 CLIP이 통과했다고 box/mask/class 라벨을 그대로 승계하지 않는다.

검증기 추가 학습과 후속 모델 학습은 현재 실행의 필수 조건이 아니다. 성능 개선 여부는 별도 실험으로 확인하며 CLIP score 상승을 후속 성능 향상으로 대신 보고하지 않는다.
